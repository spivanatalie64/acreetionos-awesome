# AcreetionOS Awesome WM Edition

A tiling window manager configuration for Awesome WM, themed with the AcreetionOS design language.

## Color Scheme

| Token | Color | Hex |
|-------|-------|-----|
| Primary Green | Accent | `#2ecc71` |
| Background | Dark | `#121212` |
| Panel | Surface | `#1a1a1a` |
| Box | Card | `#222222` |
| Border | Divider | `#333333` |
| Text Bright | Primary | `#e5e5e5` |
| Text Dim | Muted | `#b2b2b2` |
| Storm | Blue | `#61afef` |
| Flasher | Orange | `#f39c12` |
| Purple | Accent | `#9b59b6` |
